title: 常见问题与故障处理
description: 排查本地启动、邮箱连接、模型、后台任务及可选功能问题。
---

## 1. 本地启动失败

| 现象 | 检查方向 |
| --- | --- |
| 启动器提示缺少便携 Node.js | 先用 Node.js 24 执行便携运行环境准备 |
| 端口占用 | 使用 `pnpm local:start --port 3001`，按新地址访问 |
| 便携服务下载失败 | 查看具体下载错误，确认网络后重新运行准备命令 |
| 数据库无法启动 | 检查错误、数据目录及 PostgreSQL 主版本匹配 |
| 模拟账户登录异常 | 查看启动日志中的模拟器地址和对应账户 |

出现数据库问题时保留原数据，先依据具体错误处理，不通过直接删除数据目录完成重置。

## 2. 邮件整理失败

核对 `.env.local` 中三个专用模型变量、实际模型服务响应和数据库迁移。503、超时或校验错误会清空旧建议及选择，邮件和日志保留。

星标或数据变化后，重新生成建议。无法勾选的邮件应查看类别、星标、收件箱状态和原文引用，不通过修改前端绕过规则。

## 3. 常规助手始终给出预设答案

确认是否通过 `pnpm local:start` 使用演示模式。该模式的常规模型由模拟器提供；邮件整理的真实模型是独立配置，不能据其成功判断普通助手也已使用真实模型。

## 4. 真实邮箱授权或同步失败

核对 OAuth 回调、账户类型、密钥有效期和权限。已授权账户仍不同步时，查看服务商推送、订阅、后台任务和对应日志。

Outlook 的标签、类别和文件夹语义不同，确认规则目标仍存在。Microsoft 365 管理策略可能要求管理员批准。

## 5. 通知或摘要未送达

依次核对平台连接、规则/功能送达开关、Slack 目标及功能自身配置，再查看定时调度、队列消费和投递结果。网页能打开不代表后台任务都已运行。

## 6. 找不到某项功能

检查当前邮箱服务商、功能开关、外部服务配置和账户权限。深度清理、会议记录等功能有单独条件；上游移动端和扩展也不等于本仓库已有对应定制交付。

## 7. 如何准确描述问题

记录发生时间、所选账户类型、具体入口、操作和错误，以及是否使用模拟服务。附上相关错误和受控截图即可，不复制密钥或完整私人邮件内容。

区分“配置未完成”“操作失败”“结果未知”和“效果不正确”，据实际情况处理，避免重复提交已可能生效的发送或归档。
