title: 消息渠道
description: 连接 Slack、Teams 或 Telegram，并设置消息送达范围。
---

## 1. 支持的消息

“消息渠道”用于连接聊天平台，并选择规则通知、回复草稿、会前简报、跟进提醒、摘要、附件归档通知和定期更新的送达位置。

## 2. 连接步骤

1. 打开侧栏“消息渠道”，选择平台的连接入口。
2. Slack 完成 OAuth 授权；Teams、Telegram 使用页面生成的 `/connect` 命令与机器人私聊。
3. 回到页面确认已连接状态。
4. 为需要的规则和功能分别开启送达。

Teams、Telegram 的连接命令有有效期，已有流程为 10 分钟；过期后重新生成。Slack 在开启规则通知前先选择私信或允许的私有频道。

## 3. 平台能力

| 平台 | 现有交互范围 |
| --- | --- |
| Slack | 草稿查看、编辑和发送，以及受支持的归档、已读等快捷操作 |
| Microsoft Teams | 接收通知与草稿；编辑和发送草稿需回到邮件助手 |
| Telegram | 可发送准备好的草稿；不支持在该平台编辑草稿 |

不要按一个平台的卡片能力推断另一平台提供相同操作。

## 4. 规则与功能的送达设置

规则可选择仅通知或附带回复草稿。功能送达还需要其本身已经启用，例如摘要已设置发送计划、跟进已配置条件。

检查通知时分别核对：平台连接、对应规则或功能的渠道开关、功能自己的配置。断开渠道不会删除原规则、摘要计划和跟进设置。

## 5. 管理员配置

自主部署前需建立平台应用或机器人并填写对应凭据。配置变量和回调入口见[消息推送与后台任务](/zh-CN/jobs-and-webhooks)。仓库的 Slack、Teams、Telegram 原始部署说明继续作为参数参考保留。
