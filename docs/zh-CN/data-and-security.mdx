## 1. 数据位置

| 数据 | 保存位置或责任方 |
| --- | --- |
| 真实邮件及服务商草稿 | Gmail 或 Outlook 邮箱；应用可保存同步所需的邮件数据 |
| 应用账户、规则和业务记录 | 应用 PostgreSQL 数据库 |
| 客户端邮件状态 | 对应宿主的 SQLite 存储 |
| 邮件整理样本、建议和归档日志 | 独立模拟邮箱对应的数据库记录 |
| 本地演示数据库和凭据 | `.context/local-dev/` |
| 便携程序 | `.context/native/` |

停用或删除一个界面功能，不等于删除数据库、邮箱或外部平台中的全部副本。

## 2. AI 请求的数据范围

启用真实模型后，相关邮件内容、附件解析结果或上下文可能发送到配置的模型服务。邮件整理中导入的邮件也会在点击分析时发送到该服务。

本地演示的常规 AI 使用预设响应。连接真实模型时，应根据实际使用的供应商设置确认数据处理和保留方式。

## 3. 敏感信息处理

常规 AI 可配置 `SENSITIVE_DATA_POLICY_DEFAULT`：

| 设置 | 行为 |
| --- | --- |
| `ALLOW` | 按原内容发送 |
| `REDACT` | 遮盖扫描识别出的敏感内容后发送 |
| `BLOCK` | 发现匹配项后停止该次请求 |

现有扫描主要针对疑似凭据、令牌和银行卡号，不能作为全部个人信息或医疗信息的识别保证。邮件整理的模型调用独立实现，不能据常规助手的设置推断它执行了同样的扫描。

## 4. 账户及授权

邮箱、日历、云盘和消息渠道使用各自授权。Google 标签与 Outlook 类别、文件夹的权限和语义不同，修改规则前应确认选中的邮箱。

组织管理员查看成员统计，需要成员授予对应访问权限；这不意味着管理员通过组织页面获得邮件正文访问能力。

## 5. 删除与撤销

归档保留邮件内容，删除通常将其移到服务商的删除区域。取消外部服务连接会停止相应连接，但不会删除外部平台的数据。

会议记录中的“删除笔记”只删除应用中的记录；已发出的摘要邮件和邮箱草稿仍是独立副本。MCP 的浏览器退出与客户端令牌撤销也不同，停用方法见[命令行与 MCP 接入](/zh-CN/cli-and-mcp)。
