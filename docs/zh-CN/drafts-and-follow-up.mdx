---
title: 回复草稿、跟进与摘要
description: 配置回复风格、待回复状态、跟进提醒和定时摘要。
---

## 1. 自动生成草稿

在“智能助手”的设置中启用自动回复草稿。应用为需要回复的邮件准备草稿，自动草稿设置本身不会发送这些内容。

草稿置信度用于控制生成范围：全部、标准或高置信度。生成后核对收件人、事实、日期、承诺和附件，再发送。

## 2. 写作设置

| 设置 | 建议填写的内容 |
| --- | --- |
| 写作风格 | 长度、正式程度、称呼、语气及语言习惯 |
| 个人指令 | 稳定的个人背景和通用偏好 |
| 邮件签名 | 草稿末尾需要的签名 |
| 草稿知识库 | 回复常见问题所需的已确认资料 |

具体的匹配条件和操作应写入规则，避免把大量单次任务堆入通用写作设置。知识库资料变化后，及时更新旧事实。

## 3. 待回复与等待回复

开启相应规则后，需要本人答复的会话标记为“待回复”，已发送且等待对方回答的会话标记为“等待回复”。邮箱中既有标签或类别可能仍使用 `To Reply`、`Awaiting Reply` 标识。

跟进提醒分别配置双方未回复的等待时长，以及是否起草催办邮件。已有流程在计算阈值时排除周六和周日；新回复到达或本人回复后会更新对应标记。

## 4. 邮件摘要

1. 在助手设置启用摘要并打开配置。
2. 选择哪些规则匹配到的邮件加入摘要。
3. 设置按日或按周发送及发送时间。
4. 选择邮件和已连接的消息渠道。

摘要功能受账户权限和部署配置影响。把邮件加入摘要不会自动归档；需要归档时，应在规则中另行配置该操作。

## 5. 故障检查

草稿内容不合适时，先核对写作设置、知识库和匹配规则。提醒未送达时，核对提醒条件、后台定时任务和消息渠道。配置扫描或样例预览，与实际邮箱中的历史记录应分别核对。
