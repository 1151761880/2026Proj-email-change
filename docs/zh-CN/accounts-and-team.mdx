## 1. 邮箱账户

一个登录用户可以连接多个邮箱。规则、助手设置、统计和消息渠道按邮箱账户保存。调整配置、创建规则或处理邮件时，先确认当前账户。

邮箱权限过期、撤销或订阅异常时，从账户设置重新连接。受管理的 Microsoft 365 账户可能需要租户管理员批准。

## 2. 组织角色

从账户菜单创建或进入组织管理。每个邮箱账户同时只能属于一个组织。

| 角色 | 主要权限 |
| --- | --- |
| 所有者 | 管理组织并转移所有权 |
| 管理员 | 管理成员、组织规则及已获授权的统计 |
| 成员 | 查看成员并使用分配到本人的组织规则 |

转移后，原所有者成为管理员。邀请链接有有效期，接收者需使用与邀请邮箱一致的账户登录并接受。

## 3. 共享规则

所有者和管理员可创建组织规则，并同步到成员账户。新成员加入时获得现有规则；修改或删除组织规则会同步到成员副本。

成员可启停自己的副本，但不能改写组织管理的规则定义。规则须同时满足组织级和成员副本启用条件。消息渠道操作不用于组织规则，应在各成员账户中单独配置。

## 4. 统计访问

成员活动统计默认不向管理员开放，需要成员同意后才可访问相应统计和用量。该权限不赋予管理员通过组织页面读取邮件正文的能力。

## 5. API 密钥与功能可用性

公共 API 密钥由有权限的账户配置，使用方法见[公共 API](/zh-CN/api)。不要用其他账户的密钥来解释当前邮箱的访问范围。

组织席位、付费及部分功能权限取决于部署和计费设置。当前本地演示会绕过部分检查，不能据演示环境推断生产权限。
