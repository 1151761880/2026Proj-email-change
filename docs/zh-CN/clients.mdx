## 1. 网页端

网页端提供主要功能和完整管理配置。默认本地入口为 `http://localhost:3000/mail`，部署后使用自己的应用地址。

## 2. 桌面端

仓库包含 Electron 桌面客户端。先启动本地网页应用，再在项目根目录执行：

```sh
pnpm desktop
```

桌面端默认连接 `http://localhost:3000`。连接其他部署时，使用 `INBOX_ZERO_APP_URL` 环境变量。登录通过系统浏览器完成，并通过 `inboxzero://` 协议返回；该标识为已有协议名称。

可打开多个邮箱窗口，窗口账户和尺寸会保存并在再次启动时恢复。新邮件通知需要应用仍在运行。

## 3. 通知与诊断

macOS 和受支持的 Linux 启动器可显示未读标记；现有 Windows 客户端不显示数字未读徽标。后台新邮件通知不显示发件人或主题预览。

桌面诊断会生成性能追踪及系统、应用和邮件引擎状态文件。录制入口、文件位置和可选 Sentry 上报见 `apps/desktop/README.md`。

## 4. 打包

需要生成安装包时，可按平台执行：

```sh
pnpm --filter @inboxzero/desktop dist:win
pnpm --filter @inboxzero/desktop dist:mac
```

产物位于 `apps/desktop/release/`。签名、公证和自动更新需配置相应发布凭据及更新来源；本页命令不表示已有可下载的定制版安装包。

## 5. 浏览器扩展与移动客户端

上游 Tabs 扩展用于 Gmail 分类标签页，Outlook 不适用。规则同步需要对应扩展和服务配置。

本仓库当前列出的应用包含网页和 Electron 桌面端，未包含上游移动客户端或 Tabs 扩展的源码。原文中的下载入口属于上游产品资料，不能直接视为本定制版的交付或本地服务兼容性承诺。
