## 1. 文档基线

中文文档整理日期为 2026 年 10 月 13 日，面向当时工作区中的十组邮件小助手定制版。项目源自 Inbox Zero；上游原作者和许可证信息继续保留。

## 2. 当前定制内容

| 方向 | 工作区中的主要内容 |
| --- | --- |
| 中文与品牌 | 简体中文界面、中文日期及品牌资源 |
| Windows 本地运行 | 便携运行环境、独立数据库/缓存及启动器 |
| 邮件整理 | 固定模拟邮箱、真实模型配置、原文引用核对及人工确认归档 |
| 开发配置整理 | 移除专用开发工具规则和相关脚本引用 |
| 外部接入包整理 | 集中保存在 `extras/ai-integrations/`，暂不启用 |
| 中文文档 | 原文备份及独立中文目录、术语和文档导航 |

以上是定制内容说明，不是新建的正式发布版本，也不表示所有功能在真实服务上均已验证。是否已提交、打包或部署，以对应 Git、构建和运行记录为准。

## 3. 上游更新记录

原有 `docs/changelog.mdx` 和 `docs/changelog-entries/` 记录上游更新。中文版保留其原文作为参考，不将上游发布日期改写成本项目的发布日期。

## 4. 后续维护

使用方式变化时，直接更新对应中文页面。已弃用或尚属设计的内容应明确标注，不通过复制旧方案来推断当前行为。
