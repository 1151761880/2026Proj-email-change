## 1. 项目简介

十组邮件小助手基于 Inbox Zero 开源项目进行中文界面、品牌和本地运行方式适配，提供 Gmail、Outlook 邮件管理及 AI 辅助功能。网页端采用 Next.js，桌面端采用 Electron，两者共用邮件核心和界面组件。

用户可通过邮件助手查看邮件、编写回复、设置自动化规则、清理历史邮件，以及连接日历、附件存储和消息渠道。

## 2. 主要功能

| 功能 | 用途 |
| --- | --- |
| 邮箱管理 | 阅读会话，编写、回复和转发邮件，管理草稿、星标、标签与文件夹 |
| 智能助手 | 用自然语言查询邮件、生成内容及配置自动化规则 |
| 邮件整理 | 分析独立测试邮箱，展示分类依据，由用户选择并确认归档 |
| 批量清理 | 按发件人或类别归档、退订、标记已读或删除邮件 |
| 跟进与摘要 | 标记待回复会话，提醒跟进，按计划生成邮件摘要 |
| 日历与会议 | 查询可用时间，提供预约链接，生成会前简报及会议记录 |
| 附件与集成 | 将附件归档到云盘，利用外部服务的信息辅助回复 |
| 团队协作 | 管理组织成员、共享规则和经成员同意的活动统计 |

## 3. 运行模式

| 模式 | 邮箱和模型来源 | 适用范围 |
| --- | --- | --- |
| 本地演示 | 模拟邮箱及其他模拟服务；常规 AI 使用预设响应 | 熟悉界面和检查操作流程 |
| 邮件整理 | 独立模拟邮箱；配置后可调用真实模型 | 检查逐封分类、原文依据及确认归档流程 |
| 真实邮箱部署 | 用户授权的 Gmail/Outlook，以及实际配置的模型和后台服务 | 处理真实邮件，需完成授权及部署配置 |

邮件整理页面的归档只改变其独立模拟邮箱。它没有接入真实 Gmail/Outlook 的归档操作，也不执行已有自动化规则。

## 4. 功能适用条件

日历、云盘、消息渠道和会议记录需要各自的连接与配置；部分功能还受邮箱服务商、账户权限、计费设置或试用开关影响。源码中包含一个功能，不表示当前运行环境已配置或验证该功能。

外部 AI 客户端接入包暂存于 `extras/ai-integrations/`。它们与应用内部的 AI 模型调用相互独立，当前按未启用的可选扩展保留。
