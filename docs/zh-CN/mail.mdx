## 1. 选择邮箱与视图

登录后选择要操作的邮箱账户，再打开收件箱、草稿、归档或其他视图。多个账户的规则、授权和设置分别保存，切换账户后应重新确认当前操作对象。

Gmail 使用标签组织邮件；Outlook 同时使用类别和文件夹。归档、删除及移动操作的目标由对应邮箱服务商决定。

## 2. 阅读和查找

点击会话查看往来邮件及附件。可通过搜索框、标签、类别、文件夹或收件箱分组缩小范围。看到列表中的摘要后，需要阅读全文时应打开会话。

邮件界面可以利用本地存储显示已同步的数据。离线状态、尚未同步或正文仍在加载的状态，应按页面提示分别处理；当前列表不能保证包含服务商中的全部邮件。

## 3. 管理邮件

| 操作 | 效果 |
| --- | --- |
| 已读/未读 | 改变阅读状态 |
| 星标 | 标记需要关注的邮件 |
| 标签、类别或文件夹 | 改变组织方式 |
| 归档 | 移出收件箱，保留邮件 |
| 删除 | 移入服务商的删除区域，恢复受服务商规则限制 |

批量操作前核对选择范围。邮件整理页面另有独立的确认归档规则，见[邮件整理](/zh-CN/mail-triage)。

## 4. 编写、回复与转发

1. 点击编写入口，或在会话中选择回复、回复全部、转发。
2. 检查发件账户、收件人、抄送和密送。
3. 编辑主题与正文，需要时添加附件。
4. 查看发送状态；未发送的内容保存在草稿流程中。

聊天中的图片用于给助手提供上下文，不能直接作为待发邮件的附件。发送附件应通过邮件编辑器添加。

## 5. 网络中断与发送状态

共享邮件引擎保存操作状态，并向界面显示准备、执行及结果。网络故障时，应依据具体状态判断是否重试。服务商结果尚未确认时，连续重新发送可能造成重复邮件，先查看原操作和邮箱发送记录。

## 6. Outlook 使用要点

Google Calendar 对应 Outlook Calendar，Google Drive 对应 OneDrive/SharePoint。受管理的 Microsoft 365 租户可能需要管理员批准授权。授权被撤销或订阅异常时，从账户设置重新连接对应邮箱。
