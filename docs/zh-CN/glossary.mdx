## 1. 邮件术语

| 文档用语 | 英文或标识 | 含义 |
| --- | --- | --- |
| 邮箱账户 | Email account | 一个已连接的 Gmail/Outlook 邮箱 |
| 会话 | Thread / Conversation | 关联的一组邮件 |
| 标签 | Label | Gmail 中用于组织邮件的标记 |
| 类别 | Category | Outlook 中的分类标记 |
| 文件夹 | Folder | Outlook 邮件所在的容器 |
| 归档 | Archive | 移出收件箱，保留邮件 |
| 草稿 | Draft | 尚未发送的邮件内容 |
| 待回复 | To Reply | 需要用户回复的会话状态 |
| 等待回复 | Awaiting Reply | 用户已发送，正在等待对方回复 |
| 跟进 | Follow-up | 对尚未完成回复的会话进行提醒或处理 |

界面显示名称可能已中文化；既有邮箱标签、用户自定义名称和协议字段保留原标识。

## 2. AI 与自动化术语

| 文档用语 | 含义 |
| --- | --- |
| 智能助手 | 通过自然语言查询邮件或执行受支持的任务 |
| 自动化规则 | 由匹配条件和一个或多个操作组成的处理定义 |
| 分类建议 | 模型生成的分类结果及解释，尚不等同于已执行操作 |
| 原文依据 | 从所分析邮件逐字提取的引用 |
| 模型服务 | 接收请求并返回 AI 输出的服务 |
| 模型角色 | 聊天、回复草稿或分类等用途对应的模型配置 |
| 服务模拟器 | 用于本地运行或测试的替代服务 |
| MCP | 外部 AI 客户端连接工具服务的协议 |

## 3. 部署与测试术语

“自主部署”指在自己的运行环境配置应用与配套服务。“开发服务”指本机运行和调试网页应用的进程。“迁移”指数据库结构变更。

单元测试、模拟器测试、真实模型测试和真实邮箱端到端测试的依赖边界不同，结果应分别记录。流程运行成功不能直接说明模型分类正确或真实邮箱收发已经验证。
