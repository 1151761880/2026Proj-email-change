# 原始文档备份

`2026-10-13-original.tar.gz` 保存开始整理中文版前的文档，包括 `docs/` 中的正文、图片、站点配置和接口规格，以及仓库根目录和各模块已有的 Markdown 文档。

备份取自当时的工作区，包含尚未提交的文档修改。中文版位于 `docs/zh-CN/`，后续编辑不改变这份备份。

查看备份内容：

```sh
tar -tzf archives/documentation/2026-10-13-original.tar.gz
```

需要取回原文时，在单独的空目录中解压，避免覆盖当前文档：

```sh
tar -xzf archives/documentation/2026-10-13-original.tar.gz -C <空目录>
```
